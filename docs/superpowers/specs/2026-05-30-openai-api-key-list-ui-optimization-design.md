# OpenAI 兼容提供商 - API 密钥列表 UI 优化

## 概述

优化"编辑 OpenAI 兼容提供商"页面底部的 API 密钥列表区域，解决当前布局拥挤、信息交错、可读性差的问题。

## 当前问题

当前表格布局中，每行密钥需要塞入：序号、状态、密钥输入框、代理展开区、权重、操作按钮，共 5 个维度信息，导致：
- 列宽过窄，内容折叠重叠
- 状态徽章样式不明确
- 密钥明文/密文切换操作不够显眼
- 权重输入框过宽（占用整行）
- 代理 URL 默认展开，占用额外高度

## 目标

将拥挤的表格行重构为**扁平卡片式列表**，每张卡片横向排列核心字段，代理作为可折叠的高级设置。

## 设计规范

### 整体布局

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ [状态徽章]  sk-0Z1W•••••••aF1                    权重 [1]   [↑展开高级设置] │
│            [👁️ 切换] [📋 复制]                    代理: [socks5://...]     │
│                                                       [测试] [删除]         │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 卡片结构

| 区域 | 字段 | 布局 |
|------|------|------|
| 左侧 | 状态徽章 | 固定宽度 80px |
| 中部 | 密钥输入 + 操作图标 | flex-grow |
| 右侧 | 权重步进器 + 操作按钮 | 固定宽度 |

### 字段规范

#### 1. 状态徽章

| 状态 | 样式 | 内容 |
|------|------|------|
| 未测试 | 灰色背景 + 灰色文字 + "未测试" | `#6B7280` 背景 |
| 可用 | 绿色背景 + 绿色文字 + "可用" + 延迟ms | `#10B981` 背景 |
| 失败 | 红色背景 + 红色文字 + "异常" | `#EF4444` 背景 |
| 加载中 | 蓝色背景 + 旋转图标 + "测试中..." | `#3B82F6` 背景 |

- 徽章高度：24px，内边距：4px 8px
- 失败状态 hover 时显示错误信息 tooltip

#### 2. 密钥输入

- **类型**：password（默认脱敏）
- **格式**：显示为 `sk-0Z1W•••••••aF1`（保留前 8 位 + 后 4 位）
- **操作图标**（右侧）:
  - 眼睛图标：切换明文/密文
  - 复制图标：一键复制到剪贴板
- **禁用态**：降低透明度 50%

#### 3. 权重输入

- **组件**：数字步进器（已有 WeightStepper 组件可复用）
- **宽度**：固定 80px
- **范围**：min=1, max=100
- **样式**：边框 + 内部 +/- 按钮

#### 4. 代理 URL（高级设置）

- **默认态**：收起，仅显示"展开高级设置"链接
- **展开态**：显示输入框，占卡片底部整行
- **输入框宽度**：200px
- ** Placeholder**：`可选代理 URL (如 socks5://...)`

#### 5. 操作按钮

| 按钮 | 样式 | 行为 |
|------|------|------|
| 测试 | 次级按钮（Outlined） | 现有逻辑不变 |
| 删除 | 红色高亮危险按钮 | 点击后二次确认弹窗 |

#### 6. 删除确认弹窗

- **标题**：`确认删除此 API 密钥？`
- **内容**：显示密钥脱敏预览
- **按钮**：取消（次级）、确认删除（危险按钮）

## 交互行为

### 密钥操作

| 操作 | 行为 |
|------|------|
| 输入密钥 | 实时脱敏显示，状态重置为"未测试" |
| 切换明文 | 眼睛图标切换，输入框 type 在 password/text 间切换 |
| 复制 | 复制到剪贴板，显示通知 "已复制" |
| 展开代理 | 点击"展开高级设置"，下方展开代理输入框 |
| 测试 | 发送测试请求，状态变为"测试中..."，完成后显示"可用+延迟ms"或"异常" |
| 删除 | 弹出确认弹窗，确认后删除，列表重新渲染 |

### 响应式

- **桌面（>768px）**：卡片横向两行布局
- **移动端（≤768px）**：卡片纵向堆叠，字段全宽
